# claude-statusline

Claude Code için oh-my-posh tabanlı status line: model, efor, context %, maliyet, MCP sayısı.

Kurulum (Windows):

```powershell
git clone https://github.com/bahadir-unal/claude-statusline.git
cd claude-statusline
powershell -ExecutionPolicy Bypass -File .\kur.ps1
```

Gereksinimler: Node.js, oh-my-posh (kur.ps1 yoksa kurar), bir Nerd Font (`oh-my-posh font install meslo`).
